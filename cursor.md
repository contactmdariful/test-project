# Cursor

This is a **Next.js** app on **Node.js**, written in **TypeScript**.

## Tech stack

- **Runtime:** Node.js
- **Language:** TypeScript (strict)
- **Framework:** Next.js (App Router)
- **Package manager:** npm

## Conventions

- Use TypeScript for all app code. Avoid `any` unless there is no practical alternative.
- Prefer the App Router (`app/`), Server Components by default, and Client Components only when needed (`"use client"`).
- Keep API routes in `app/api/`.
- Use `.ts` / `.tsx`. Do not add new `.js` / `.jsx` files.
